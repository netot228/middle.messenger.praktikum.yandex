### Учебный проект веб мессенджера

## Стек технологий

- Пакетный менеджер pnpm
- Сборка на Vite
- Vanilla-TS
- Шаблонизатор Handlebars
- Препроцессор Sass
- ....будет дополняться

## Установка

- `pnpm install` — установка стабильной версии,
- `pnpm dev` — запуск версии для разработчика,
- `pnpm build` — сборка стабильной версии.

## Конфигурация Vite настроена для запуска на 3000 порту

**На данном этапе, для удобства навигации реализована псевдомаршрутизация (ибо пока не дошли до того как это делать) на базе изменения значения hash объекта location**

\*в верхнем правом углу экрана доступна кнопка с меню навигации (решение временное)

### Проект поддерживает светлую теменую тему основанную на настройках системы

## Подготовлены следующие страницы с использованием шаблонизатора Handlebars

\* ниже примеры ссылок будут указаны для localhost

1. Страница входа [доступна по ссылке](http://localhost:3000/)
   ![Форма авторизации](/screens_set/login.jpg)

- есть подсветка требования заполненности поля (подсветится по клику на кнопку войти)
  ![Форма авторизации](/screens_set/login_alarm_field.jpg)

2. Страница регистрации [доступна по ссылке](http://localhost:3000/#page=registration)
   ![Форма регистрации](/screens_set/registration.jpg)

- также есть подсветка требования заполненности поля (подсветится по клику на кнопку регистрация)
  ![Форма авторизации](/screens_set/registration_alarm.jpg)

3. Страница чата [доступна по ссылке](http://localhost:3000/#page=chat)
   ![Страница чата](/screens_set/chat_page.jpg)
   для страницы чата использованы моки:

- мок листинга чатов, структура взята из урока, листинг сгенерирован ИИ
- мок диалога, структура не была известна, так что было сгененировано экспромптом с наличием внутри текста и картинок

- для листинга чата был создан хелпер, чтобы, в случае отсутствия аватара вместо картинки подставлялись инициалы
- для будущей вставки изображений/файлов подставлены инпуты соответствующих типов (input type="file")
  ![вставки изображений/файлов](/screens_set/chat_upload_menu.jpg)
- добавлен сет эмоджи
  ![сет эмоджи](/screens_set/chat_smiles_set.jpg)
- всплывашка для добавления/удаления пользователя
  ![добавления/удаления пользователя](/screens_set/chat_add_remove_user.jpg)

4. Страница профиля [доступна по ссылке](http://localhost:3000/#page=profile) (можно перейти как из меню, так и с кнопки иконки в шапке навигаци)
   ![Страница профиля](/screens_set/profile.jpg)
   внтури страницы профиля также настроены переходы на редактирования данных

- редактирование данных и аплоад аватара
  ![вставки изображений/файлов](/screens_set/profile_edit.jpg)
- смена пароля
  ![вставки изображений/файлов](/screens_set/profile_change_pass.jpg)

5. Страница 404 [доступна по ссылке](http://localhost:3000/#page=404)
   ![404](/screens_set/404.jpg)

6. Страница 500 [доступна по ссылке](http://localhost:3000/#page=5xx)
